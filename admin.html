🗳️ मतदान निकाल (opinion.html)

हे GitHub token पेक्षा वेगळं लॉगिन आहे — एकदाच सेटअप, खाली सूचना.

हे कसं सेटअप करायचं? (एकदाच)
  1. Firebase Console → तुमचा opinion.html चा प्रोजेक्ट उघडा.
  2. Build → Authentication → Get started → "Email/Password" provider चालू करा (Enable).
  3. Authentication → Users → Add user → तुमचा स्वतःचा email + password टाका (हाच वर वापरा).
  4. Firestore → Rules मध्ये जाऊन खालील नियम paste करा आणि Publish करा:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /votes/{voteId} {
      allow create: if request.resource.data.vote in ['होय','नाही']
                    && request.resource.data.keys().hasOnly(['vote','timestamp']);
      allow read: if request.auth != null;
      allow update, delete: if false;
    }
    match /voter_details/{id} {
      allow create: if true;
      allow read: if request.auth != null;
      allow update, delete: if false;
    }
    match /meta/counts {
      allow read: if true;
      allow create: if request.resource.data.keys().hasOnly(['yes','no'])
                    && request.resource.data.yes is int
                    && request.resource.data.no is int;
      allow update: if
        (request.resource.data.yes == resource.data.yes + 1
         && request.resource.data.no == resource.data.no) ||
        (request.resource.data.no == resource.data.no + 1
         && request.resource.data.yes == resource.data.yes);
      allow delete: if false;
    }
  }
}

    प्रत्येक नोंदीसमोरचं 🗑️ बटण दाबून ती नोंद कायमची delete करता येईल (चुकीच्या/duplicate नोंदींसाठी).

    वरचं CSV बटण फक्त ज्यांनी नाव/मोबाईल/क्षेत्र दिलं त्यांचीच यादी देतं. हे बटण votes मधल्या सगळ्या नोंदी (कोणी नाव न देता फक्त मत दिलं असेल तरी) एकत्र करून एकच अंतिम यादी देतं — रेल्वे अधिकाऱ्यांना पाठवण्यासाठी वापरा. एकूण संख्या live counter शी जुळते का हेही दाखवेल.

    📋 संपूर्ण सार्वजनिक यादी (voters-list.html)

    साईटवरचं नवीन पान — फक्त नाव + मत (होय/नाही) सगळ्यांना दाखवतं, पत्ता/मोबाईल कधीच नाही.

    नवीन मतांना आपोआप हे जोडलं जातं. फक्त आधीच्या (backfill च्या आधीच्या) जुन्या नोंदींसाठी हे एकदा दाबा — voter_public मधल्या ज्या नोंदींना अजून "मत" (होय/नाही) जोडलेलं नाही, त्यांना voter_details मधून मत घेऊन जोडतं. सुरक्षित आहे, कितीही वेळा चालवू शकता — आधीच जोडलेल्या नोंदींना काहीही होत नाही.

    🌐 सार्वजनिक यादी (साईटवर सगळ्यांना दिसणारी "पाठिंबा देणारे नागरिक")

    इथून हटवलेली नोंद साईटवरच्या यादीतून लगेच (live) नाहीशी होईल. Duplicate नावं इथूनच साफ करा.

    📁 सरकारी कागदपत्रे व पुरावे

    RTI, CPGRAMS, आपले सरकार, पत्रे, PDF/फोटो अपलोड करा. मजकूर वाचणे (OCR) तुमच्याच ब्राऊझरमध्ये फुकट चालतं — कुठलाही API-key, बिलिंग किंवा सर्व्हर लागत नाही. OCR मजकूर पूर्ण-मजकूर शोधासाठी (search) वापरला जातो. सारांश तुम्ही स्वतः लिहिता, आणि तो नेहमी "Admin-Reviewed" म्हणून दाखवला जातो.
