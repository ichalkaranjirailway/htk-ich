नवीन नोंद जोडा

Add a new evidence entry — updates data.js and saves the proof file into proofs/ automatically on your computer.

हा browser support करत नाही. कृपया Google Chrome किंवा Microsoft Edge (desktop) वापरा.

Step 1 — तुमचा project folder कनेक्ट करा

तो folder निवडा ज्यात data.js आणि proofs folder आहे (उदा. तुमचा ichalkaranji-railway-archive repo folder, तुमच्या computer वर local ठेवलेला).

Step 2 — नोंदीचे तपशील भरा

Image, PDF, किंवा video चालेल. Automatically proofs/ folder मध्ये save होईल.
