🗳️ मतदान निकाल (opinion.html)

हे GitHub token पेक्षा वेगळं लॉगिन आहे — एकदाच सेटअप, खाली सूचना.

हे कसं सेटअप करायचं? (एकदाच)
  1. Firebase Console → तुमचा opinion.html चा प्रोजेक्ट उघडा.
  2. Build → Authentication → Get started → "Email/Password" provider चालू करा (Enable).
  3. Authentication → Users → Add user → तुमचा स्वतःचा email + password टाका (हाच वर वापरा).
  4. Firestore → Rules मध्ये जाऊन खालील नियम paste करा आणि Publish करा:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /votes/{voteId} {
      allow create: if request.resource.data.vote in ['होय','नाही']
                    && request.resource.data.keys().hasOnly(['vote','timestamp']);
      allow read: if request.auth != null;
      allow update, delete: if false;
    }
    match /voter_details/{id} {
      allow create: if true;
      allow read: if request.auth != null;
      allow update, delete: if false;
    }
    match /meta/counts {
      allow read: if true;
      allow create: if request.resource.data.keys().hasOnly(['yes','no'])
                    && request.resource.data.yes is int
                    && request.resource.data.no is int;
      allow update: if
        (request.resource.data.yes == resource.data.yes + 1
         && request.resource.data.no == resource.data.no) ||
        (request.resource.data.no == resource.data.no + 1
         && request.resource.data.yes == resource.data.yes);
      allow delete: if false;
    }
  }
}
  • FIREBASE_CONFIG आता इथे वेगळं भरायची गरज नाही — opinion.html प्रमाणेच हे पेजही firebase-config.js मधली values आपोआप वापरतं.

    • जुन्या bug मुळे counter मध्ये काही मतं मोजली गेली नव्हती त्यासाठी — हे दाबल्यावर votes मधल्या सगळ्या खऱ्या नोंदी मोजून होय/नाही आकडा बरोबर केला जाईल. सुरक्षित आहे, कितीही वेळा चालवू शकता.

    प्रत्येक नोंदीसमोरचं 🗑️ बटण दाबून ती नोंद कायमची delete करता येईल (चुकीच्या/duplicate नोंदींसाठी).

    🌐 सार्वजनिक यादी (साईटवर सगळ्यांना दिसणारी "पाठिंबा देणारे नागरिक")

    इथून हटवलेली नोंद साईटवरच्या यादीतून लगेच (live) नाहीशी होईल. Duplicate नावं इथूनच साफ करा.

    📧 अधिकाऱ्यांना कळवणारा Email

    वरचाच GitHub Token वापरून, "अधिकाऱ्यांना थेट कळवा" बटणाचा मजकूर, ईमेल आयडी आणि तो बटण कधी सक्रिय होईल ती वेळ इथून बदलता येईल.

    मजकुरात {{STAT_LINE}} आणि {{SITE_URL}} हे दोन शब्द जसेच्या तसे राहू द्या — पाठवताना तिथे आपोआप खरी मतसंख्या आणि साईटची लिंक भरली जाते. ते काढू नका किंवा त्यांचं स्पेलिंग बदलू नका.

    या तारीख-वेळेपूर्वी बटण दिसेल पण disabled (राखाडी) राहील — क्लिक करता येणार नाही. ही वेळ उलटल्यावर बटण आपोआप (पान रिफ्रेश न करताही) सक्रिय होईल.
