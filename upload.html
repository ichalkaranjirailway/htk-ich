🚂 नवीन पुरावा नोंद — थेट साईटवर जोडा

फॉर्म भरा, फाईल निवडा, "साईटवर टाका" दाबा — काम आपोआप होईल, GitHub वर जाऊन काहीही manually करावं लागणार नाही.

🔑 एकदाच सेटअप

हे तुमच्या ब्राऊझरमध्येच साठवलं जातं (फक्त तुमच्याच डिव्हाइसवर) — पुढच्या वेळी परत टाकावं लागणार नाही.

Token कसा बनवायचा? (एकदाच, 2 मिनिटं)
  1. github.com/settings/tokens/new इथे जा (लॉगिन असावं लागेल)
  2. Note: "htk-ich admin" असं काहीही नाव द्या
  3. Expiration: "No expiration" किंवा "1 year" निवडा
  4. खाली "repo" या checkbox वर टिक करा (यामुळे फक्त तुमच्या repos edit करण्याची परवानगी मिळते)
  5. खाली "Generate token" दाबा, जो हिरवा code दिसेल तो copy करून वरच्या बॉक्समध्ये paste करा
